# experiments/

Entry points, grouped by the kind of evidence they produce. Each group's
SLURM wrappers are in the matching `scripts/<group>/` folder, and results go
to `$SIDLENS_WORK/derived/`.

Every AR and DiffGRM experiment below also runs on a OneDiffRec grid weight
state (`--ckpt grid:<key>@<state>`, `src/sidlens/grid/`); the grid pipeline
(`scripts/grid/`, runbook `docs/clusters/GRID_RUNBOOK.md`) runs them all and
writes to `$SIDLENS_WORK/results_remote/<group>/<experiment>/<dataset>/<task>/<paradigm>/<map>/<state>/`.
The retrospective analyses of saved lists run on grid runs through
`python -m sidlens.grid.saved_lists`.

| Folder | Evidence | Contents |
|---|---|---|
| `structure/` | Static properties of the 27 SID maps; no model is run | `exp1_atlas/` (per-digit attributes, naming, co-purchase), `exp2_geometry/` (radius, refinement, digit deletion), `semantic_mapping/` (the eight structure figures; `anomaly_audit.py`), `exp3_collision_causes/` (why items share a SID: post-processing, near-duplicates, residual hub codes, MQ digit redundancy; faiss refits), `exp4_final_maps/` (all of the above rerun on the final-run v3 tables of both catalogs, 54 maps + 39 ZCR twins, plus the direct RQ-VAE post-processing test from its checkpoints, the MQ encoder audit, ZCR costs and test-target collision exposure; 2026-10-20) |
| `retrospective/` | CPU audits of archived model outputs | `exp1_reveal_order`, `exp2_prefix`, `exp3_collisions`, `exp4_next_two` (see `retrospective/README.md`); `exp6_time_structure` (review days in the data and in the exp3/4/6/7 outputs); `exp7_collision_credit` (exp6 copy knockouts re-scored at item level by target–history relation) |
| `controlled/` | New GPU inference on frozen checkpoints, protocol declared first | Diffusion decoding: `exp1_matched_beam/`, `exp2_fixed_orders/` (the templates; see `CLAUDE.md`). AR causal interventions (run on the CIAI cluster): `exp3_ar_history_patching/` (history-item replacement + residual patching), `exp4_ar_copy_circuit/` (prefix-matched copying: replication, attention-edge knockout, heads), `exp5_ar_next_two_conditioning/` (clamp item 1 of the next-two model), `exp6_ar_copy_in_decoding/` (copy knockout inside the archived beam decoder; repeat vs new targets), `exp9_ar_order_vs_time/` (swap the two most recent items, split by their review days), `exp10_ar_last_digit_sibling/` (last-digit edge knockout: does the model copy or avoid the code of a history item that matches the target's prefix). `exp11_ar_copy_grid/` (exp3 A, exp4 R/K and exp6 rerun unchanged on the 12 accepted retrained AR next-item models; retrained vs original RQ-KMeans 3×128). DiffGRM interventions: `exp7_diffusion_history_use/` (replacement, copying, cross-attention knockout), `exp8_diffusion_copy_route/` (encoder spread vs direct decoder read), `exp12_diffusion_activation_patching/` (paired runs, r1 replaced or a revealed digit set to a sibling's code; encoder slots, decoder residuals and per-block cross-attention outputs patched both ways; self-attention edge knockout), `exp13_diffusion_step_switch/` (r1 replaced at single reveal steps of the decode), `exp14_diffusion_decode_perturbations/` (exp8's copy block held through beam search, HR by target relation; r1↔r2 swap; history shifted by 1 or 5 slots). All 20 next-item checkpoints, 2026-10-14; plan `docs/plans/DIFFUSION_MECHANISMS_PLAN.md`. Each has `protocol.md`, `README.md` or `RESULTS.md`. |
| `additions/` | The four experiments added for the OneDiffRec grid (`docs/plans/COPYING_GRID_PLAN.md` §4.3), protocols declared 2026-10-21 | `n1_prefix_conditioning/` (does the copy need the whole prefix or only the previous digit token), `n2_ar_prefix_match/` (query, key or value; early-layer prefix reads; head DLA; base-model induction heads), `n3_copy_dose/` (copy reads scaled by alpha inside the runs' own beam search), `n4_no_training_baselines/` (copy rule and popularity against the saved lists). Grid states only; see `additions/README.md` |
| `representation/` | Observational reads of captured activations, protocol declared first | `exp1_ar_digit_decoding/` (logit lens + user-disjoint probes on the AR test-split captures), `exp2_ar_sae/` (TopK SAEs on train-split captures: copy / prefix-match latents, target semantics, same-day bursts, with causal latent ablations), `exp3_ar_information_map/` (self-forced captures, SAEs at every second layer, a census labelling every latent, tuned lens and trie-constrained SID decoders), `exp4_diffusion_reveal_trace/` (DiffGRM: what the decode holds at every reveal step and decoder block; run 2026-10-13, provisional), `exp5_diffusion_encoder_features/` (DiffGRM encoder: linear probes at three sites, TopK SAEs with causal ablation of spread and identity latents, a description autoencoder in the style of NLAs; 20 checkpoints, 2026-10-14) |
| `substrate/` | New model weights, protocol declared first; outputs go to `$SIDLENS_WORK/runs/` | `exp1_ar_next_item_retrain/` (recreates the 18 Qwen-AR next-item models of the width-128/512 grid with the recorded August recipe; arm B trains ZCR versions of five RQ-KMeans maps; `check.py` accepts a model only if it matches the archived predictions within the declared limits) |
| `paper_www27/` | Paper packaging | `export_paper_data.py`: hashed tables behind the SidLens numbers in the WWW'27 draft |
