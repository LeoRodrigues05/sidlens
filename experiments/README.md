# experiments/

Entry points, grouped by the kind of evidence they produce. Each group's
SLURM wrappers are in the matching `scripts/<group>/` folder, and results go
to `$SIDLENS_WORK/derived/`.

| Folder | Evidence | Contents |
|---|---|---|
| `structure/` | Static properties of the 27 SID maps; no model is run | `exp1_atlas/` (per-digit attributes, naming, co-purchase), `exp2_geometry/` (radius, refinement, digit deletion), `semantic_mapping/` (the eight structure figures; `anomaly_audit.py`), `exp3_collision_causes/` (why items share a SID: post-processing, near-duplicates, residual hub codes, MQ digit redundancy; faiss refits) |
| `retrospective/` | CPU audits of archived model outputs | `exp1_reveal_order`, `exp2_prefix`, `exp3_collisions`, `exp4_next_two` (see `retrospective/README.md`); `exp6_time_structure` (review days in the data and in the exp3/4/6/7 outputs); `exp7_collision_credit` (exp6 copy knockouts re-scored at item level by target–history relation) |
| `controlled/` | New GPU inference on frozen checkpoints, protocol declared first | Diffusion decoding: `exp1_matched_beam/`, `exp2_fixed_orders/` (the templates; see `CLAUDE.md`). AR causal interventions (run on the CIAI cluster): `exp3_ar_history_patching/` (history-item replacement + residual patching), `exp4_ar_copy_circuit/` (prefix-matched copying: replication, attention-edge knockout, heads), `exp5_ar_next_two_conditioning/` (clamp item 1 of the next-two model), `exp6_ar_copy_in_decoding/` (copy knockout inside the archived beam decoder; repeat vs new targets), `exp9_ar_order_vs_time/` (swap the two most recent items, split by their review days), `exp10_ar_last_digit_sibling/` (last-digit edge knockout: does the model copy or avoid the code of a history item that matches the target's prefix). DiffGRM interventions: `exp7_diffusion_history_use/` (replacement, copying, cross-attention knockout), `exp8_diffusion_copy_route/` (encoder spread vs direct decoder read). Each has `protocol.md`, `README.md` or `RESULTS.md`. |
| `representation/` | Observational reads of captured activations, protocol declared first | `exp1_ar_digit_decoding/` (logit lens + user-disjoint probes on the AR test-split captures), `exp2_ar_sae/` (TopK SAEs on train-split captures: copy / prefix-match latents, target semantics, same-day bursts, with causal latent ablations), `exp3_ar_information_map/` (self-forced captures, SAEs at every second layer, a census labelling every latent, tuned lens and trie-constrained SID decoders) |
| `substrate/` | New model weights, protocol declared first; outputs go to `$SIDLENS_WORK/runs/` | `exp1_ar_next_item_retrain/` (recreates the 18 Qwen-AR next-item models of the width-128/512 grid with the recorded August recipe; arm B trains ZCR versions of five RQ-KMeans maps; `check.py` accepts a model only if it matches the archived predictions within the declared limits) |
| `paper_www27/` | Paper packaging | `export_paper_data.py`: hashed tables behind the SidLens numbers in the WWW'27 draft |
